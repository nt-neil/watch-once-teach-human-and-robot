# 第四類示範錄影腳本（給使用者，約 5 分鐘）

## 前置（1 分鐘）

1. 開一個無痕視窗，只開 demo 頁：http://127.0.0.1:18765/todo-demo.html（避免書籤列／其他分頁入鏡）。
2. 按 F5 重新整理頁面，確認是空白初始狀態。
3. 開 OBS 開始錄影，確認錄到瀏覽器視窗。

## 操作（約 1–2 分鐘，每步之間停 2 秒、滑鼠放慢）

1. 在輸入框輸入「鳳梨酥 3 盒」，停 2 秒。
2. 按「新增」鈕，確認列表出現該項，停 2 秒。
3. 勾選該項左側核取框，確認出現綠色完成樣式，停 2 秒。
4. 按「清除已完成」鈕，確認列表清空，停 2 秒。

## 結束

1. 停止 OBS 錄影。
2. 到 ~/Movies/OBS/ 找到最新檔案，把檔名回給指揮。

## 注意

- 按錯直接重錄一遍，不要剪輯。
- 畫面只會有 demo 頁，不要切到其他視窗。
